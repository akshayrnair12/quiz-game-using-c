# quiz-game-using-c

This is a simple command-line quiz application written in C. It loads multiple-choice questions from a text file, asks them one by one, and keeps track of the user's score.

📦 Files Included
simple.c — Main C source code for the quiz application.

quiz.txt — Text file containing the quiz questions.

scores.txt — Automatically generated file to store scores of users.

🚀 How to Run
Open Dev-C++ or any C IDE.

Open the file simple.c and compile the program.

Make sure quiz.txt is in the same folder as the compiled .exe file.

Run the program. It will ask your name and then quiz you with multiple-choice questions.

After finishing the quiz, your score will be saved in scores.txt.
